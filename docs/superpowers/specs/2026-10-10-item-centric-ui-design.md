# 设计：以道具为中心的界面，游戏公告关联

日期：2026-10-10。在 `2026-10-09-forecast-rebuild-and-web-app-design.md` 之上修改界面结构。

## 要解决的问题

用户打开程序先看概览，想了解每个道具本赛季、往届赛季的价格和各种详情。现在同一个道具的信息分散在
概览、道具库详情、价格走势、价格预测四个页面；概览看不到往届赛季；也没有办法知道某次游戏更新是否影响了
某个道具的价格（比如金矿成为新装备或任务的材料）。

## 已确认的决定

1. **主线是「概览 → 道具详情」。** 一个道具的所有信息放在一页 `/item/<道具类型>`，各品质在页内切换。
2. **概览默认只看本赛季**；往届赛季、赛季对比在道具详情里看。
3. **游戏公告按名字匹配**：Steam 补丁说明里直接点名的道具，在价格图上打标记。大模型判断间接影响以后再加。

## 页面结构

```
概览（本赛季，所有道具）
  └─ 点一个道具 → 道具详情
        ├─ 价格走势（可切换赛季，图上标出游戏更新）
        ├─ 下一小时成交价（只在本赛季）
        ├─ 赛季对比
        ├─ 相关游戏更新
        ├─ 预测
        ├─ 道具资料（折叠）
        └─ 挂单明细（折叠）
```

侧边栏：概览 → ② 查看与分析（价格走势、价格预测、赛季回测、行情报告、装备行情）→ ① 获取数据（道具库、数据采集、
定时采集、本机数据库）→ 设置。

## 概览

- 顶部：赛季提示条（交易行未开放时写明开放日和原因）、搜索、排序（涨跌幅 / 挂单数 / 名称）、分类筛选。
- 卡片（每种道具一张，各品质合并）：图标、中文名、最新价、比 24 小时前、**7 天**小走势图（原 48 小时）、
  **下一小时范围**一行（如「下一小时：17–23」）、最近 14 天有补丁点名时显示补丁标记。
- 本赛季无数据：交易行未开放 → 显示上赛季最后价格并标「往届」（沿用）；已开放未采集 → 「去采集」。
- 点卡片进入道具详情。概览不放赛季切换、大图、预测。

## 道具详情

1. **头部**：图标、中文名、类别、品质切换（单品质不显示）、最新价、24 小时涨跌、本赛季挂单数；
   「获取最新数据」「一键预测」。未追踪的道具只显示资料和「追踪」。
2. **价格走势**：赛季下拉（默认本赛季）、粒度（每小时 / 4 小时 / 每天）；补丁竖线（点名本道具的醒目，
   其他大更新淡灰），悬停显示补丁名和日期；保留框选统计。
3. **下一小时成交价**：现有卡片，只在本赛季显示。
4. **赛季对比**：横轴「赛季开始后第几天」（从各赛季交易开放日算），每赛季一条日中位价线；下附表格，
   每赛季一行：开盘、最高、最低、收盘、平均、挂单数。
5. **相关游戏更新**：点名本道具的补丁，倒序；日期、补丁名、原文片段（高亮道具名）、Steam 链接、
   更新前后 3 天日中位价变化（如「更新后 3 天 +18%」；数据不足显示「–」）。点一条，主图跳到该时间。
6. **预测**：最近一次预测的小图和结论（比基准准多少），链接到价格预测页。
7. **道具资料**（折叠）：参数、各品质价格、挂单统计和本赛季挂单查询（原道具库详情页内容）。
8. **挂单明细**（折叠）：原价格走势页的挂单表。

## 游戏公告

- 来源：Steam `ISteamNews/GetNewsForApp`（appid 2016590），免费，无 key，不消耗 DarkerDB 额度。
- 只保留补丁类：标题含 Hotfix / Patch / Update / Season，或来自补丁说明源。
- 范围：首次回溯到 2024-09（第 4 赛季），之后增量。
- 存储：`data/announcements.json`（id、日期、标题、URL、正文纯文本）。启动时距上次更新超过 6 小时自动拉取；
  设置里有「更新游戏公告」。拉取失败用本机缓存，界面提示「公告暂时无法更新」，其他功能不受影响。
- 匹配：用道具类型的英文名（各品质共用，如 Ruby），不分大小写、整词、允许复数；记录命中的那一句作为片段。
- 页面写明局限：只认直接点名；常见词可能误匹配；片段为英文原文。

## 迁移

- `/catalog/<道具类型>` 重定向到 `/item/<道具类型>`；概览卡片改为进入道具详情。
- 价格走势页保留（自由时间段、全部挂单），其「下一小时成交价」卡片移到道具详情。
- 赛季回测从价格预测页拆为独立页面。

## 实施顺序（每步可单独使用）

1. 游戏公告：拉取、存储、匹配、接口。
2. 道具详情页：组合现有的走势、品质、下一小时、资料、挂单。
3. 赛季对比：后端按赛季第几天对齐，前端图和表。
4. 公告上图：主图标记、相关更新列表、更新前后涨跌。
5. 概览改版：7 天走势、下一小时范围、补丁标记、点进详情。
6. 侧边栏重排、旧链接重定向、赛季回测拆页。

## 测试

- 后端：固定 Steam 公告样本测匹配（大小写、复数、整词、常见词误匹配）、补丁类过滤、断网用缓存；
  赛季对齐（交易开放日为第 0 天、缺数据的日子）；更新前后涨跌的计算和数据不足。
- 前端：详情页各部分渲染、赛季与品质切换、未追踪道具、旧链接重定向、概览卡片新内容。
- 最后用钴矿、金矿的真实数据在浏览器里走一遍。

## 不做

- 大模型判断补丁的间接影响（以后在匹配结果上加）。
- 手动添加事件标记。
- 概览上的赛季切换。
