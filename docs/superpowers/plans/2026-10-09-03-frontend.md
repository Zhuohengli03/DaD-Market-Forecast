# Frontend Implementation Plan (3/3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the vanilla `frontend/` with a React + TypeScript single-page app: dashboard, market explorer, forecast workbench with live logs and run history, collection/scheduler control, and settings (seasons, items config).

**Architecture:** Vite app under `frontend/`; server state lives in TanStack Query hooks over a typed envelope-aware fetch client; long jobs stream over SSE; ECharts renders price/forecast/backtest charts; URL search params hold the selected item/season/range so views are shareable; i18next provides zh/en.

**Tech Stack:** Node 25 / npm 11, Vite 6, React 18, TypeScript 5, react-router-dom 6, @tanstack/react-query 5, echarts 5 + echarts-for-react 3, Tailwind CSS 4 (`@tailwindcss/vite`), i18next + react-i18next, lucide-react, vitest + @testing-library/react + jsdom, @playwright/test.

**Spec:** `docs/superpowers/specs/2026-10-09-forecast-rebuild-and-web-app-design.md` (sections 8, 9, 10)

## Global Constraints

- All commands run in `frontend/` unless stated. Tests: `npm test` (vitest, non-watch). Type check: `npm run typecheck` (`tsc --noEmit`).
- Backend contract is plan 2: every response `{ok, data, error, meta}`; SSE at `/api/jobs/{id}/events` with events `log` and `status`.
- Timestamps from the API are ISO UTC; display with the browser's local time zone via `fmtTs`.
- Item/season/range/resolution selection lives in URL search params (`item`, `season`, `start`, `end`, `res`).
- Every mutation shows a toast on success and on failure (with the server's `error` text).
- Dev server proxies `/api` to `http://localhost:5001`. Production build goes to `frontend/dist` and is served by the backend.
- Branch `rebuild/forecast-and-webapp`; commit per task, no push; message format `<type>: <description>`, no attribution trailer.

## Review Focus

1. Backend down or returning HTML (proxy error): the client must throw a readable `ApiError`, not crash on `JSON.parse`. → Task 1 test `throws readable error on non-JSON response`.
2. A forecast run whose `beats_baseline` is false: the result view must show the "did not beat baseline" state prominently and still render the chart with the naive forecast. → Task 4 test `BacktestTable` + `RunStatusBanner shows not-better state`.
3. SSE connection closing before the terminal status (server restart): the hook must stop spinning and surface "connection lost" instead of hanging forever. → Task 4 test `useJobEvents reports disconnect`.
4. Season form with end before start or overlapping: the 422 error text from the server appears inline next to the form, and the list is unchanged. → Task 6 test `SeasonEditor shows server validation error`.
5. Listings table with `total = 0` after filtering: an empty state, not a blank table or a crash on `data[0]`. → Task 3 test `ListingsTable renders empty state`.

`frontend/src/api/client.ts`:
```ts
export type Meta = Record<string, unknown>
export interface Envelope<T> { ok: boolean; data: T; error: string | null; meta: Meta | null }

export class ApiError extends Error {
  status: number
  constructor(status: number, message: string) { super(message); this.status = status; this.name = 'ApiError' }
}

type Params = Record<string, string | number | boolean | undefined | null>

function qs(params?: Params): string {
  if (!params) return ''
  const entries = Object.entries(params).filter(([, v]) => v !== undefined && v !== null && v !== '')
  if (!entries.length) return ''
  return '?' + entries.map(([k, v]) => `${encodeURIComponent(k)}=${encodeURIComponent(String(v))}`).join('&')
}

function encodePath(path: string): string {
  return path.split('/').map((seg, i) => (i === 0 ? seg : encodeURIComponent(seg))).join('/')
}

async function request<T>(method: string, path: string, body?: unknown, params?: Params): Promise<{ data: T; meta: Meta | null }> {
  let res: Response
  try {
    res = await fetch('/api' + encodePath(path) + qs(params), {
      method,
      headers: body !== undefined ? { 'Content-Type': 'application/json' } : undefined,
      body: body !== undefined ? JSON.stringify(body) : undefined,
    })
  } catch (e) {
    throw new ApiError(0, `network error: ${(e as Error).message}`)
  }
  let env: Envelope<T> | null = null
  const ct = res.headers.get('content-type') || ''
  if (ct.includes('application/json')) {
    try { env = (await res.json()) as Envelope<T> } catch { env = null }
  }
  if (!env) {
    const text = (await res.text().catch(() => '')).slice(0, 200)
    throw new ApiError(res.status, `HTTP ${res.status}: ${text || 'non-JSON response'}`)
  }
  if (!res.ok || !env.ok) throw new ApiError(res.status, env.error || `HTTP ${res.status}`)
  return { data: env.data, meta: env.meta }
}

export const api = {
  get: <T>(path: string, params?: Params) => request<T>('GET', path, undefined, params),
  post: <T>(path: string, body?: unknown) => request<T>('POST', path, body),
  put: <T>(path: string, body: unknown) => request<T>('PUT', path, body),
  del: <T>(path: string) => request<T>('DELETE', path),
}
```

export function fmtNum(n: number | null | undefined, digits = 2): string {
  return n === null || n === undefined || Number.isNaN(n) ? '–' : n.toFixed(digits)
}
export function fmtPct(x: number | null | undefined, digits = 1): string {
  if (x === null || x === undefined || Number.isNaN(x)) return '–'
  const v = (x * 100).toFixed(digits)
  return (x >= 0 ? '+' : '') + v + '%'
}
export function fmtTs(iso: string | null | undefined, opts: { withDate?: boolean } = { withDate: true }): string {
  if (!iso) return '–'
  const d = new Date(iso)
  if (Number.isNaN(d.getTime())) return iso
  return opts.withDate === false ? d.toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })
    : d.toLocaleString([], { month: 'short', day: '2-digit', hour: '2-digit', minute: '2-digit' })
}
export function fmtRelative(iso: string | null | undefined): string {
  if (!iso) return '–'
  const ms = Date.now() - new Date(iso).getTime()
  const h = Math.round(ms / 3.6e6)
  if (Math.abs(h) < 1) return `${Math.round(ms / 6e4)} min`
  if (Math.abs(h) < 48) return `${h} h`
  return `${Math.round(h / 24)} d`
}
export function toCsv(rows: Record<string, unknown>[]): string {
  if (!rows.length) return ''
  const keys = Object.keys(rows[0])

import { useSearchParams } from 'react-router-dom'
import { useCallback } from 'react'

export function useUrlState(key: string, fallback = ''): [string, (v: string) => void] {
  const [params, setParams] = useSearchParams()
  const value = params.get(key) ?? fallback
  const set = useCallback((v: string) => {
    setParams(prev => { const next = new URLSearchParams(prev); if (v) next.set(key, v); else next.delete(key); return next }, { replace: true })
  }, [key, setParams])
  return [value, set]
}

type Kind = 'ok' | 'error' | 'warn'
interface Toast { id: number; msg: string; kind: Kind }

export function ToastProvider({ children }: { children: ReactNode }) {
  const [items, setItems] = useState<Toast[]>([])
  const push = useCallback((msg: string, kind: Kind = 'ok') => {
    const id = Date.now() + Math.random()
    setItems(t => [...t, { id, msg, kind }])
    setTimeout(() => setItems(t => t.filter(x => x.id !== id)), kind === 'error' ? 6000 : 3000)
  }, [])
  const tone = { ok: 'bg-emerald-600', error: 'bg-red-600', warn: 'bg-amber-600' }
  return (

      {children}

      </div>
    </Ctx.Provider>
  )
}

import { useEffect, useRef, useState } from 'react'
import type { JobStatus } from './types'

const TERMINAL: JobStatus[] = ['succeeded', 'failed']

export function useJobEvents(jobId: string | null) {
  const [lines, setLines] = useState<string[]>([])
  const [status, setStatus] = useState<JobStatus | null>(null)
  const [disconnected, setDisconnected] = useState(false)
  const statusRef = useRef<JobStatus | null>(null)
  useEffect(() => {
    setLines([]); setStatus(null); setDisconnected(false); statusRef.current = null
    if (!jobId) return
    const es = new EventSource(`/api/jobs/${jobId}/events`)
    es.addEventListener('log', (e: MessageEvent | { data: string }) => setLines(l => [...l, (e as { data: string }).data]))
    es.addEventListener('status', (e: MessageEvent | { data: string }) => {
      const s = (e as { data: string }).data as JobStatus
      statusRef.current = s; setStatus(s)
      if (TERMINAL.includes(s)) es.close()
    })
    es.onerror = () => { if (!statusRef.current || !TERMINAL.includes(statusRef.current)) setDisconnected(true); es.close() }
    return () => es.close()
  }, [jobId])
  return { lines, status, disconnected }
}

import { useModels, useStartForecast } from '../../api/hooks'
import { useSelection } from '../../components/SelectorBar'
import { Button } from '../../components/ui/Button'
import { Field, inputCls } from '../../components/ui/Field'
import { useToast } from '../../components/ui/Toast'

const BASELINES = ['naive', 'seasonal_naive_24']
const HORIZONS = [24, 48, 72, 168]

export function ForecastForm({ onStarted }: { onStarted: (jobId: string) => void }) {
  const { t } = useTranslation()
  const sel = useSelection()
  const models = useModels()
  const start = useStartForecast()
  const toast = useToast()
  const [horizon, setHorizon] = useState(72)
  const [coverage, setCoverage] = useState(0.9)
  const [chosen, setChosen] = useState<string[]>(['ridge', 'hgb', 'rf', 'ets', 'arima'])
  const [error, setError] = useState<string | null>(null)
  const optional = (models.data ?? []).filter(m => !BASELINES.includes(m))
  const toggle = (m: string) => setChosen(c => (c.includes(m) ? c.filter(x => x !== m) : [...c, m]))
  const submit = () => {
    setError(null)
    if (!sel.item || !sel.season) { setError(`${t('common.item')} / ${t('common.season')}`); return }
    start.mutate({ item: sel.item, season_id: sel.season, horizon_hours: horizon, models: chosen.filter(m => optional.includes(m)), coverage },
      { onSuccess: id => { toast.push(t('forecast.pending'), 'ok'); onStarted(id) }, onError: e => { setError((e as Error).message); toast.push((e as Error).message, 'error') } })
  }
  return (
    <div className="space-y-3">
      <div className="grid grid-cols-2 gap-3">
        <Field label={t('common.item')}><select className={inputCls} value={sel.item} onChange={e => sel.setItem(e.target.value)}>{sel.items.map(i => <option key={i.name} value={i.name}>{i.name}</option>)}</select></Field>
        <Field label={t('common.season')}><select className={inputCls} value={sel.season} onChange={e => sel.setSeason(e.target.value)}>{sel.seasons.map(s => <option key={s.id} value={s.id}>{s.name}</option>)}</select></Field>
        <Field label={t('forecast.horizon')}><select className={inputCls} value={horizon} onChange={e => setHorizon(Number(e.target.value))}>{HORIZONS.map(h => <option key={h} value={h}>{h} h</option>)}</select></Field>
        <Field label={t('forecast.coverage')}><select className={inputCls} value={coverage} onChange={e => setCoverage(Number(e.target.value))}>{[0.8, 0.9, 0.95].map(c => <option key={c} value={c}>{Math.round(c * 100)}%</option>)}</select></Field>
      </div>
      <Field label={t('forecast.models')} error={error}>
        <div className="flex flex-wrap gap-3 text-sm">
          {BASELINES.map(m => <label key={m} className="flex items-center gap-1 text-[var(--muted)]"><input type="checkbox" checked disabled aria-label={m} />{m}</label>)}
          {optional.map(m => <label key={m} className="flex items-center gap-1"><input type="checkbox" checked={chosen.includes(m)} onChange={() => toggle(m)} aria-label={m} />{m}</label>)}
        </div>
      </Field>
      <Button onClick={submit} loading={start.isPending}>{t('forecast.start')}</Button>
    </div>
  )
}

import type { ForecastRun } from '../../api/types'
import { fmtNum } from '../../lib/format'

const BASELINES = ['naive', 'seasonal_naive_24']

export function BacktestTable({ run }: { run: ForecastRun }) {
  const { t } = useTranslation()
  const members = new Set([run.selected.name, ...run.selected.members.map(m => m.name)])
  const rows = [...run.backtest.models].sort((a, b) => {
    const ab = BASELINES.indexOf(a.name), bb = BASELINES.indexOf(b.name)
    if (ab !== -1 || bb !== -1) return (ab === -1 ? 99 : ab) - (bb === -1 ? 99 : bb)
    return (a.mae_mean ?? 1e9) - (b.mae_mean ?? 1e9)
  })
  const cols: [string, keyof typeof rows[0]][] = [[t('forecast.mae'), 'mae_mean'], [t('forecast.maeH1'), 'mae_h1'], [t('forecast.maeH24'), 'mae_h24'], [t('forecast.rmse'), 'rmse_mean'], [t('forecast.mase'), 'mase_mean'], [t('forecast.dir'), 'direction_acc']]

      <div className="text-xs text-[var(--muted)]">{t('forecast.origins')}: {run.backtest.origins} · {t('forecast.evalHorizon')}: {run.backtest.horizon}h · {t('forecast.coverageActual')}: {run.backtest.coverage == null ? '–' : Math.round(run.backtest.coverage * 100) + '%'} / {Math.round(run.backtest.nominal_coverage * 100)}%</div>

      {Object.entries(run.backtest.failures).map(([n, e]) => <div key={n} className="text-xs text-[var(--bad)]">{n}: {e}</div>)}

const empty: SeasonInput = { name: '', start: '', end: null, note: '' }

function SeasonForm({ initial, onSubmit, pending, error, submitLabel, onCancel }: { initial: SeasonInput; onSubmit: (s: SeasonInput) => void; pending: boolean; error: string | null; submitLabel: string; onCancel?: () => void }) {
  const { t } = useTranslation()
  const [s, setS] = useState(initial)
  return (
    <div className="flex flex-wrap items-end gap-3">
      <Field label={t('settings.seasonName')}><input className={inputCls} value={s.name} onChange={e => setS({ ...s, name: e.target.value })} /></Field>
      <Field label={t('settings.seasonStart')}><input type="datetime-local" className={inputCls} value={toInput(s.start || null)} onChange={e => setS({ ...s, start: fromInput(e.target.value) ?? '' })} /></Field>
      <Field label={t('settings.seasonEnd')}><input type="datetime-local" className={inputCls} value={toInput(s.end)} onChange={e => setS({ ...s, end: fromInput(e.target.value) })} /></Field>

      <Button loading={pending} disabled={!s.name || !s.start} onClick={() => onSubmit(s)}>{submitLabel}</Button>
      {onCancel && <Button variant="ghost" onClick={onCancel}>{t('common.cancel')}</Button>}
    </div>
  )
}

export function SeasonEditor() {
  const { t } = useTranslation()
  const seasons = useSeasons(); const m = useSeasonMutations(); const toast = useToast()
  const [editing, setEditing] = useState<Season | null>(null)
  const [error, setError] = useState<string | null>(null)
  const fail = (e: unknown) => { setError((e as Error).message); toast.push((e as Error).message, 'error') }
  const okay = () => { setError(null); setEditing(null); toast.push(t('settings.saved')) }
  return (
    <div className="space-y-4">
      <table className="w-full text-sm"><thead className="text-left text-[var(--muted)]"><tr><th className="py-1">{t('settings.seasonName')}</th><th>{t('common.start')}</th><th>{t('common.end')}</th><th>{t('settings.note')}</th><th></th></tr></thead>

            <td className="text-right space-x-2"><Button size="sm" variant="ghost" onClick={() => { setEditing(s); setError(null) }}>✎</Button><Button size="sm" variant="danger" onClick={() => m.remove.mutate(s.id, { onSuccess: okay, onError: fail })}>{t('common.delete')}</Button></td></tr>))}</tbody></table>

        ? <SeasonForm key={editing.id} initial={editing} pending={m.update.isPending} error={error} submitLabel={t('common.save')} onCancel={() => setEditing(null)} onSubmit={s => m.update.mutate({ id: editing.id, ...s }, { onSuccess: okay, onError: fail })} />
        : <SeasonForm key="new" initial={empty} pending={m.add.isPending} error={error} submitLabel={t('common.add')} onSubmit={s => m.add.mutate(s, { onSuccess: okay, onError: fail })} />}
    </div>
  )
}
