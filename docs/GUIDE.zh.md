# Darker Market 使用指南

所有设置都在程序界面里完成，不需要改代码、配置文件或使用终端。

## 安装和启动
1. 安装 [Python 3.10+](https://www.python.org/downloads/) 和 [Node.js 20+](https://nodejs.org/)。
2. 下载本项目（GitHub 页面上的 **Code → Download ZIP**，或用 git 克隆）。
3. macOS / Linux 运行 `start.sh`，Windows 双击 `start.bat`。

第一次启动需要几分钟安装依赖，之后几秒就能打开。浏览器会自动打开 **http://localhost:5001**。

## 设置向导
第一次打开时会弹出设置向导，以后可以在「设置 → 重新运行设置向导」再次打开。

| 步骤 | 做什么 |
|---|---|
| 环境 | 选择数据存在内置数据库（推荐，自动创建）还是你自己的 Postgres |
| API key | 粘贴 DarkerDB key（[在这里创建](https://darkerdb.com/dashboard/api-keys)，勾选 `darkerdb.live` 和 `darkerdb.data`） |
| 初始化 | 选择要追踪的道具，程序会下载道具库、导入赛季、采集本赛季挂单并试做第一次预测 |
| 自动采集 | 设置多久采集一次（最少 30 秒），页面会估算每月消耗多少 DarkerDB 额度 |

## 各页面
| 页面 | 用途 |
|---|---|
| 概览 | 每种道具一张卡片，同一道具的各品质放在一起；看最新价格、24 小时涨跌和近 48 小时走势 |
| 道具库 | 所有可交易道具；点一行进入详情页，看各品质价格、挂单统计和全部参数 |
| 数据采集 | 添加或移除道具、立即采集、只采集没有数据的道具 |
| 定时采集 | 开关自动采集，给单个道具设置自己的间隔或每天固定时间 |
| 价格走势 | 每小时中位价和中间 50% 价格带；可框选时间段统计；「获取最新数据」「一键预测」 |
| 价格预测 | 预测未来 24 到 168 小时，并说明是否比「沿用上一小时价格」更准 |
| 装备行情 | 带随机词条的装备按词条数值范围筛选，实时查看挂单和每日价格 |
| 设置 | API key、DarkerDB 额度、采集间隔、赛季、网络（局域网访问和端口）、语言 |

## DarkerDB 额度
免费方案每月 10,000 次。左下角显示剩余额度；每个会用到 DarkerDB 的操作都会先显示预计消耗（往多了估），超出剩余额度时会先确认。任务记录里能看到每次实际消耗。

## 预测为什么可信
- 挂单先变成每小时中位价，每个特征只看更早的时间（有测试保证）。
- 每种方法都在历史上滚动回测，和「沿用上一小时」「沿用昨天同一时刻」两个基准比较。
- 只有比基准准 2% 以上、并且至少有 5 次回测时才采用模型，否则显示基准并说明原因。
- 可信区间来自真实的回测误差，页面会显示它实际命中了多少。

## 常见问题
- **提示 key 无效**：确认是 v2 key，并勾选了上面两个权限。
- **获取最新数据总是没有新挂单**：DarkerDB 本身还没有更新的数据时会这样，页面会显示它最新一条挂单的时间。
- **预测说「没有找到比基准明显更准的方法」**：说明这段时间价格接近随机波动，最好的猜测就是当前价格。
- **想用手机访问**：在「设置 → 网络」打开局域网访问并点「立即重启」，只在可信网络下这样做。
- **端口被占用**：在「设置 → 网络」换一个端口，点「立即重启」。

## 开发者
```bash
python -m pip install -r requirements-dev.txt
python -m backend                               # 接口，:5001
cd frontend && npm run dev                      # 页面，:5173，热更新
python -m pytest -q                             # 后端和预测测试
cd frontend && npm test && npm run e2e          # 前端单元测试和浏览器测试
python tools/readme_banner.py && python tools/readme_howto.py   # 重新生成 README 动画
```
